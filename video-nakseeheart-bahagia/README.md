## 2. Hook (0–4.5 s)
- **Audio/visual:** petikan sebenar penceramah *"Hakikatnya kebahagiaan sebenar… apabila kita dapat mentaati perintah Allah."*
- **Headline animasi (soalan, bukan kata-kata penceramah):** `DI MANA` / **`BAHAGIA SEBENAR?`**
- **Teknik:** punch-in 1.32× ke 1.12×, kemudian slow push-in ke wajah. Latar dikaburkan secara sinematik manakala subjek kekal tajam (depth-of-field melalui matte). Ada soft impact, shimmer dan partikel emas. Ditutup dengan kilat putih-emas dan whoosh ke permulaan ucapan.
- **Alternatif hook** untuk varian A/B: "BAHAGIA BUKAN PADA HARTA?" atau "APA YANG MEMBUAT KITA BENAR-BENAR BAHAGIA?"

## 4. Transkrip & subtitle
Transkripsi dibuat dengan Whisper large-v3 (cap masa perkataan) dan disemak secara manual. **Kata-kata penceramah tidak diubah.**

```
[01.50] Tidak ada siapa dalam dunia ini tidak mahukan bahagia.
[04.58] Semua orang menginginkan kebahagiaan.
[07.88] Tetapi kebahagiaan tidak semestinya dengan duit yang banyak.
[10.70] Kebahagiaan tidak semestinya pangkat yang tinggi.
[13.28] Kebahagiaan tak semestinya kita dapat memiliki harta benda yang banyak, kereta mewah.
[18.24] Tapi hakikatnya kebahagiaan sebenar, apabila kita dapat mentaati perintah Allah,
[23.20] dapat melaksanakan ibadah dengan setenang-tenangnya.
[25.92] Itulah satu kebahagiaan yang sangat luar biasa.
```

Gaya subtitle: Montserrat ExtraBold 54 px, putih, **kata kunci emas** (KATA UTAMA huruf besar). Perkataan muncul satu demi satu mengikut sebutan, kata kunci diberi pop dan glow. Maksimum 2 baris. Kawasan selamat x 60–940 (mengelak rel ikon TikTok), dan subtitle tidak bertindih dengan lower third.

## 6. B-roll & kesan visual
- **B-roll:** penceramah tidak menyediakan rakaman tambahan, jadi rakaman asal digunakan sebagai visual utama (punch-in dan close-up). Babak 26.6–31.9 s menggunakan **ilustrasi prosedur** (langit subuh, masjid, god rays, figura bermuhasabah). Visual ini jelas sebuah ilustrasi dan tidak dipersembahkan sebagai rakaman sebenar.
- **Cadangan B-roll stok** jika mahu menggantikannya: suasana masjid waktu Subuh, tangan menadah doa, al-Quran di rehal, langit senja, sejadah.
- **Kesan visual:** punch-in / push-in / pull-back, goyangan genggam yang minimum, depth-of-field berasaskan matte, light leak hangat ketika peralihan, kilat emas, vignette, film grain 6%, debu cahaya. Gred warna: dinding digelapkan ke *deep charcoal / warm gold*, bayang *muted teal*, dan warna kulit dikekalkan semula jadi.

## 7. Muzik, SFX & mixing
- **Muzik:** piano sinematik dengan pad strings spiritual (D major / B minor). **Disintesis sepenuhnya, jadi bebas hak cipta** ([`scripts/generate_audio.py`](scripts/generate_audio.py)). Bermula jarang, crescendo berperingkat ke klimaks (31.9–42.5 s), kemudian resolve semasa CTA.
- **Suara:** high-pass 85 Hz, denoise FFT, EQ (-2.5 dB @250 Hz, +2.5 dB @3.2 kHz) dan kompresor lembut.
- **Ducking automatik:** pengesan sampul suara menurunkan muzik ~11 dB ketika penceramah bercakap. Muzik berada 14–17 dB di bawah suara.
- **SFX (minimum):** soft impact (hook, flash, akhirat, cari/cipta/Allah), whoosh (4 peralihan), shimmer (light sweep), pop lembut (kata kunci).
- **Master:** -14 LUFS bersepadu, true-peak -1.5 dBTP (standard TikTok/Reels).

## Struktur projek & cara render semula
```
src/data/timeline.json      Garis masa suntingan (sumber kebenaran tunggal)
src/data/transcript.raw.json  Transkrip Whisper (cap masa perkataan)
src/data/subtitles.json     Dijana oleh scripts/build_subtitles.py
src/Video.tsx               Komposisi utama (susunan lapisan)
src/components/Stage.tsx    Kamera maya, latar digred, teks di belakang subjek, subjek beralfa
src/components/Text3D.tsx   Tipografi 3D (extrusion, light sweep, letter reveal), label, petikan terapung
src/components/Subtitles.tsx, LowerThird.tsx, Broll.tsx, Effects.tsx
scripts/prepare_media.sh    Proxy tegak, pembersihan suara, matte, video alfa
scripts/generate_audio.py   Muzik, SFX, ducking, mixdown -14 LUFS
```
```bash
npm install
pip install "rembg[cpu]" pillow numpy scipy
bash scripts/prepare_media.sh /path/ke/IMG_9879.mov   # ~45 min (matte 1212 bingkai pada CPU)
python3 scripts/build_subtitles.py
python3 scripts/generate_audio.py
npm run render        # -> out/nakseeheart-kebahagiaan-sebenar.mp4
```
Jika Chrome Headless tidak dapat dimuat turun, tetapkan `REMOTION_BROWSER=/path/ke/chrome-headless-shell`.
