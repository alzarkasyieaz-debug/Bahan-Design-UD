## 2. Hook (0–3.6 s)
- **Audio:** petikan sebenar *"Apa yang kita sangka, itulah yang kita akan dapat."* (86.0–89.5 s).
- **Headline (bukan kata-kata penceramah):** `HATI-HATI DENGAN` / **`SANGKAAN KITA`**.
- **Teknik:** punch-in 1.5× ke 1.3× pada wajah, kemudian slow push-in, latar kabur (depth-of-field melalui matte), partikel, soft impact. Peralihan ke ucapan penuh dengan kilat emas dan whoosh.
- **Alternatif hook:** "APA YANG KITA SANGKA, ITU YANG KITA DAPAT" atau "SANGKA BURUK BOLEH MERUNTUHKAN UKHUWAH".

## 5. Audio
- Suara dibersihkan dengan rantai yang sama seperti video 1 (high-pass, denoise, EQ, kompresor).
- Muzik piano + strings disintesis (bebas hak cipta), crescendo dari "Paling penting" ke klimaks.
- Muzik diset **perlahan** (seperti yang diminta untuk video 1): ducking -16 dB, muzik 23–30 dB di bawah suara.
- Master -14 LUFS, true-peak -1.5 dBTP.

## Render semula
```bash
ln -s ../video-nakseeheart-bahagia/node_modules node_modules   # atau: npm install
bash scripts/prepare_media.sh /path/ke/IMG_2582.mov
python3 scripts/build_subtitles.py
python3 scripts/generate_audio.py
npm run render        # -> out/nakseeheart-sangka-baik.mp4
```
Nota: matte projek ini dijana setiap 2 bingkai, dan bingkai di antaranya diinterpolasi kepada 30 fps (lihat langkah alfa dalam sejarah commit). `prepare_media.sh` versi asal menjana setiap bingkai; hasilnya setara tetapi lebih lambat.
